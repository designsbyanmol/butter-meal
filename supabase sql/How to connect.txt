How to Connect — Complete Project Setup Guide
Complete end-to-end setup for a new instance of this project. Follow every step in order.

Part 1 — Supabase Project Setup
Go to https://supabase.com and log in.

Create a New Project → choose an organization → enter a project name and a strong database password → pick the region closest to your users → Create new project.

Wait for the project to finish provisioning (~2 minutes).

Get your API keys
In your project, go to Project Settings → API Keys.

Copy the Project URL (looks like https://xxxx.supabase.co).

Copy the Publishable / anon key (starts with eyJ...).

Save both — you'll paste them into .env in Part 3.

Enable the pgcrypto extension
In Supabase, go to Database → Extensions → search pgcrypto → Enable it. (Required for password hashing.)

Part 6 — Supabase Edge Functions (Razorpay only)
The payment flow uses two Supabase Edge Functions. Deploy them with the Supabase CLI:

bash
# 1. Install the Supabase CLI
npm install -g supabase

# 2. Link to your project
supabase login
supabase link --project-ref your-project-ref

# 3. Add the Razorpay secrets (server-side only, never commit these)
supabase secrets set RAZORPAY_KEY_ID=rzp_test_xxxxx
supabase secrets set RAZORPAY_KEY_SECRET=xxxxxxxxxx

# 4. Deploy the two functions from supabase/functions/
supabase functions deploy razorpay-create-order
supabase functions deploy razorpay-verify
If you skip this step, the free-signup flow still works (invoice is created as pending), but the online payment step will fail.

Part 8 — Troubleshooting
Symptom	Cause	Fix
"Invalid phone number or password" on a known-good login	Lockout after 3 failures	DELETE FROM auth_login_attempts for that phone
Store shows "Tenant not found"	Slug typo or is_active = FALSE	Check star_veg_tenants row
Menu items not appearing	menu_version cache stale	Bump: UPDATE star_veg_tenants SET menu_version = menu_version + 1 WHERE slug = '<slug>'
Edits not saving in the admin panel	Stale update_menu_item RPC	Re-run Rewrite update items.sql or the correct tenant-scoped version
Signup fails at invoice step	Edge function missing or invoice RLS misconfigured	Deploy razorpay-create-order; re-run Harden Tenant Invoice.sql
Reviews tab is empty for a tenant	Plan isn't professional OR reviews_enabled = FALSE	Check star_veg_tenants.reviews_enabled and plan_id
Dine-in toggles don't save	dinein_enabled missing from update_tenant_info allowlist	Re-run Allow avatar to be written.sql (that version includes all fields)
dist/index.html opens blank	Opened via file://	Use npm run preview

Part 11 — Deploying to Production
Option A — Static hosting (Vercel / Netlify / Cloudflare Pages)
npm run build → produces dist/index.html.

Upload dist/ to your host.

Set a rewrite rule so every route serves index.html (the app is client-routed).

Add the deployed domain to Supabase Auth → URL Configuration → Site URL.

Option B — Single-file deployment
The dist/index.html after npm run build contains everything inlined (CSS, JS, images up to the inline limit). You can email it, drop it in a shared folder, or host it as a single file. The app must be served over HTTP(S) — never file://.

Domain + Store URLs
After deploying to https://yourdomain.com:

Store admin URL becomes https://yourdomain.com/?t=<slug>_admin

Store customer URL becomes https://yourdomain.com/?t=<slug>

Platform admin URL becomes https://yourdomain.com/?_smart-admin

Nothing needs to be re-run in SQL — the app derives all URLs from window.location.origin.
